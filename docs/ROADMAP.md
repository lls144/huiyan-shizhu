## M1 USB 摄像头稳定采集 — DONE

- **输入条件**：Insta360 Ace Pro 2、USB 线、三脚架、A3 白色背景；确认 Webcam 模式操作方法。
- **实现任务**：枚举设备；建立可配置采集模块；测量可用分辨率、帧率、延迟和持续运行稳定性；保存代表性样帧。
- **验收标准**：目标电脑可重复打开/关闭摄像头并稳定采集；设备 ID 不硬编码；真实参数和失败情况进入测试记录。
- **所需真实硬件**：USB 摄像头及固定装置。
- **是否可在宿舍完成**：是。
- **当前状态**：DONE。2026-09-03 使用 Insta360 Ace Pro 2、DirectShow、MJPG、1920×1080@30 完成 60 秒测试：1793/1793 帧成功，实测 29.869 fps，最大成功帧间隔 0.069 s，3/3 次重新打开成功。三脚架垂直俯拍和 A3 背景未在本次稳定性测试中验证，须在 M2 开始前布置。
