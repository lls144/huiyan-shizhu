# 演示视频分镜（DELIV-007，2–3 分钟 MP4）

验收要求：2–3 分钟 MP4，展示 **单次识别、连续入队、逐个出队、心跳报警** 四段指定流程，PC 结果与 PLC/LED 状态均可辨认，且与报告版本一致。

## 录制前条件（全部满足才开录）

- [ ] 冻结录制版本：记录 `git rev-parse HEAD`，与报告/PPT 一致；工作区无未提交改动。
- [ ] 真实 PLC 已完成 `--check-access` 与 `--all`，证据已归档。
- [ ] `pc/config/plc.json` 已填实际 `db_number`，且 GUI 显式传入 `--plc-config`。
- [ ] 机位：三脚架垂直俯拍 + A3 白色工作区；画面能同时看到 PC 屏、纸板物体和 PLC 实验箱。
- [ ] M9（心跳/断连报警）已冻结实现；否则第 4 段改为“未实现说明”，不得摆拍报警。

## 分镜

| 镜头 | 时长 | 画面 | 旁白/字幕要点 | 对应需求 |
|---|---|---|---|---|
| 0 片头 | 0:08 | 系统全景：PC 屏 + 摄像头 + 实验箱 + 三个纸板 | 题目、团队、一句话闭环 | SCOPE-001 |
| 1 单次识别 | 0:30 | 放入三角形；GUI 显示标签与置信度；随后入队监视 | “识别 → 离散事件 → 入队”，强调不重复入队 | VISION-002、PLC-002 |
| 2 连续入队 | 0:35 | 依次放入 triangle / rectangle / circle；队列长度 1→2→3；第 4 次触发 Full | 连续多物体、队列满处理 | VISION-003、PLC-001/004 |
| 3 逐个出队 | 0:45 | 按一次按键 → 出队 1 条 → LED 亮 1 盏；再按 → 2 盏；再按 → 3 盏 | 按键沿与去抖、“按一次出队一条”、1/2/3 映射 | PLC-002、PLC-003 |
| 4 心跳与断连 | 0:30 | 正常心跳指示；拔掉网线/停止心跳进程；约 2 s 后三灯全闪；恢复后回到正常 | 1 s 心跳、2 s 阈值、恢复条件 | COMM-002 |
| 5 收尾 | 0:12 | 队列状态、日志/证据文件、结论字幕 | 已完成范围与局限 | DOC-001 |

合计约 2:40，处于 2–3 分钟区间。

## 拍摄与后期要求

- 全程单机位不间断录制为主，避免剪辑掩盖时序；必要的画中画用于同时展示 PC 日志与实物灯。
- 关键时点加时间戳字幕（识别时刻、按键时刻、报警触发时刻），便于与日志对齐。
- 若某段未通过，如实保留并标注为“局限/失败样例”，不要补拍成成功。
- 原始录像体积大，**不提交 Git**（`.gitignore` 已忽略 `*.mp4`）；只提交最终压缩后的成片与分镜脚本，或按课程要求单独提交。
