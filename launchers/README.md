# 一键启动脚本

双击对应的 `.bat` 即可，不需要开 PowerShell、不需要敲命令。
脚本会自动切到仓库根目录并使用仓库自带的 `.venv`。

| 脚本 | 用途 | 需要什么 |
|---|---|---|
| `1-传送带分拣-真机PLC.bat` | **演示主力**：摄像头 → 三节传送带 → 真机 PLC → 实体灯 | 实验箱上电 + 网线 |
| `2-传送带分拣-不接PLC.bat` | 只看传送带动画，不连 PLC | 只要笔记本 |
| `3-传送带分拣-自动点灯自测.bat` | 开发自测：识别后自动出队点亮（**不是任务书流程**） | 实验箱上电 |
| `4-上位机GUI.bat` | 原版视觉界面（M5）：实时画面、检测、事件 | 摄像头 |
| `5-视觉存证-M2单目标.bat` | M2 单目标存证：`S` 存证 / `R` 重校准 / `Q` 退出 | 摄像头 + A3 纸 |
| `6-视觉存证-M3多目标.bat` | M3 多目标 + 光照存证：`1`–`5` 存五个场景 / `Q` 退出 | 摄像头 + 三个图形 |
| `7-PLC只读自检.bat` | 只读确认 PLC 可访问（最安全） | 实验箱上电 + 网线 |
| `8-PLC自动验收12项.bat` | 真机 12 项自动验收 | 实验箱 + 网线 |
| `9-断连报警验证.bat` | 心跳中断 2 秒 → 三盏灯全闪 | 实验箱 + 网线 |
| `0-全量自动化测试.bat` | 全量自动化回归（不碰硬件） | 只要笔记本 |

## 依赖缺失时

如果提示 `.venv not found`，在仓库根目录执行一次：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 退出方式

- `1`/`2`/`3`/`4` 关窗口，或程序跑完自动退出（脚本最后会 `pause` 让你看提示）；
- `5`/`6` 在预览窗口里按 `Q`；
- `7`/`8`/`9`/`0` 跑完自动停在 `pause`。
